## Geometry and pin alignment

`mobile/src/maps/campusGeometry.ts` contains offline OSM paths, generated by `mobile/scripts/generate-campus-map.py`. Download both extracts to a local working directory and pass their paths to that script to regenerate. No map server, key, location permission, or runtime tile request is needed.

`mobile/src/maps/geography.ts` projects longitude/latitude into local east/north meters, then rotates the map 30° clockwise to align the campus street grid. **North points toward the upper right**, as the compass indicates. The generator and overlay use the same center, meter scale, rotation, and aspect ratio. No `slice` crop or percentage clamping moves a garage to an invented position. Pins identify building centers, not vehicle entrances or individual stalls.

The map omits small unclassified details and simplifies sub-meter vertices. OSM geometry is not a survey or a source of turn-by-turn/accessibility routing. Walk times use a distance estimate to the Student Union, a detour allowance, and 75 m/min; labels mark them approximate.

## Real geography versus demo parking data

Addresses, garage stories, campus placement, and drawn street/building footprints have a geographic source. Availability, individual stall IDs, interior row arrangements, per-level capacity, feature placement, reservations, permits, and camera coverage remain samples. The reusable interior grid explicitly says its layout is illustrative; it is not a surveyed garage floor plan. Published total garage capacities are deliberately not substituted into a demo grid with fewer modeled spaces.

Live camera feeds may supply `location: { latitude, longitude }`. The Python API accepts the optional `PARKING_LATITUDE` and `PARKING_LONGITUDE` environment variables. Without a valid pair, the lot remains in the availability list and receives no fictional campus pin. Coordinates outside both campus viewports are likewise omitted from the map. Legacy API `mapX`/`mapY` fields remain compatible but do not determine geographic placement.

## Spartan Pin

`mobile/assets/spartan-pin.svg` is the approved vector master (candidate A). `npm run assets:brand` in `mobile/` regenerates the React Native path, iOS/general icon, Android adaptive and monochrome assets, splash mark, and favicon using local Chrome. Colors come from the existing navy/gold palette. Platform launcher icons and the native splash configuration take effect in a newly built native binary. The original `SpartanSpot.html` prototype uses the same mark.

Checks: `npm run typecheck`, `npm run lint`, `npm run test:map`, `npm run export:web`, and route smoke checks. Map tests check that projected garage centers are contained in their rendered OSM footprints, separate campuses remain separate, live coordinates are validated, and floor-count corrections preserve reservation references.
